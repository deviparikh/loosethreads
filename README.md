# Loose Threads

The public website for [Loose Threads](https://loosethreadsinsf.com).

This is a small, dependency-free static site hosted with GitHub Pages.

## Edit the site

- `index.html` contains the page structure and words.
- `styles.css` contains the layout and visual design.
- `brand/` contains the images and fonts used by the page.
- `CNAME` connects the site to `loosethreadsinsf.com`.

Changes pushed to the `main` branch are published by GitHub Pages.
